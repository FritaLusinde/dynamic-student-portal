# Dynamic Student Portal

A multi-page student portal website built using HTML and CSS as part of my web development labs.

## Live Website
[Click here to view the live site](https://fritalusinde.github.io/dynamic-student-portal/)

## Pages
- **Home** (`index.html`): welcome page with a news sidebar
- **Timetable** (`timetable.html`): weekly class timetable and campus map
- **Register** (`register.html`): student registration form with validation

## Features
- Responsive layout using CSS Grid
- Flexbox navigation menu
- HTML table for the timetable
- Embedded Google Map
- Registration form with required-field validation
- Shared stylesheet (`styles.css`) across all pages

## Technologies Used
- HTML5
- CSS3
- Git and GitHub
