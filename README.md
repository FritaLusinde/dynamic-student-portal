# Dynamic Student Portal

A multi-page student portal website built using HTML, CSS and JavaScript as part of my Web Application Development lab capstone project.

## Live Website
[Click here to view the live site](https://fritalusinde.github.io/dynamic-student-portal/)

## Pages
- **Home** (`index.html`): welcome page with a news sidebar and a button that loads the list of registered students
- **Timetable** (`timetable.html`): weekly class timetable with an embedded campus map
- **Register** (`register.html`): student registration form with validation

## Features
- Responsive layout using CSS Grid
- Flexbox navigation menu
- HTML table for the weekly timetable
- Embedded Google Map using an iframe
- Registration form with required-field validation
- JavaScript form validation using regular expressions (name and email)
- Student list loaded from a JSON file using the Fetch API
- Error handling for failed data loading
- Student class (OOP) to represent each student
- Shared stylesheet (`styles.css`) across all pages

## Technologies Used
- HTML5
- CSS3 (Flexbox and Grid)
- JavaScript (ES6)
- Git and GitHub

## Git Workflow
- `main`: stable, final version of the project
